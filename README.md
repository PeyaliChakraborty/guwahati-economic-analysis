# Guwahati Economic Indicators Analysis

I have been living in Guwahati since my graduation and was curious about how the city has been changing economically over the last few years. So I decided to look at the numbers myself.

This notebook looks at cost of living and employment trends in Guwahati from 2021 to 2026.

## What I analysed

- How monthly expenses (rent, groceries, transport) have changed year on year
- How the workforce is distributed across sectors
- Which sectors are growing and which are declining

## Tools used

- Python
- SQLite
- pandas
- matplotlib

## How to run

```bash
pip install pandas matplotlib
```
